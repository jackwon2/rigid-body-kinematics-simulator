웹 브라우저만 있으면 설치 없이 사용할 수 있는 교육용 강체 평면 운동학 시뮬레이터입니다.

## 탭 구성

화면 위쪽의 탭으로 세 가지 시뮬레이터를 오갑니다. 주소 끝에 `#link`, `#rot`를 붙이면 해당 탭이 바로 열립니다.

1. **강체 평면운동:** 아래 "주요 기능"의 일반 평면운동 시뮬레이터 (처음 값은 모두 0)
2. **링크 기구 (크랭크):** 크랭크-슬라이더와 4절 링크의 자세 해석 및 상대속도·상대가속도 해석 (교재 5/4–5/6절)
   - 구동 링크의 각 θ를 재생 막대로 바꾸며 각 자세의 속도·가속도, 속도·가속도 다각형, 링크별 ω·α, 커플러의 순간중심, 커플러 곡선을 표시
   - 교재 예제 5/8·5/14, 5/9·5/15, 5/12 프리셋과 벡터식 대입 풀이
3. **회전 좌표계 (코리올리):** 회전 좌표계에 대한 상대운동 v_A = v_B + ω×r + v_rel, a_A = a_B + ω̇×r + ω×(ω×r) + 2ω×v_rel + a_rel (교재 5/7절)
   - 회전 좌표계의 운동(θ₀, ω, ω̇)과 원판에 고정된 경로(직선·원호 슬롯), 경로를 따른 운동 r(t)를 지정
   - 각 항을 회전 좌표계 (i, j)·고정 좌표계 (X, Y) 성분으로 표시, "회전 좌표계에서 보기"(관측자 시점) 지원
   - 교재 예제 5/16, 5/17·5/18, 5/19 프리셋

②·③ 탭의 기본 상태는 SI 단위에 속도·가속도 입력이 모두 0이며, 교재 예제 버튼은 교재와 같은 단위(in·ft, mm)로 값을 불러옵니다.

## 주요 기능 (① 강체 평면운동)

- **강체 형상:** 곡선형 임의 강체, L-형 바, 원형 바퀴, 직사각형 판, 사용자 지정 다각형
- **형상 치수 입력 (m):** 바퀴 반지름 r, L-바의 막대 길이 L₁·L₂와 두께 w, 직사각형 b × h, 다각형 꼭짓점 좌표
- **운동 기준점 R:** 강체 위의 임의의 점을 기준점으로 선택하고, 그 점에 병진 속도·가속도를 직접 부여
- **운동 매개변수:** 기준점 병진 속도 v_R, 병진 가속도 a_R, 초기 각속도 ω₀, 각가속도 α (슬라이더 + 숫자 직접 입력)
- **탐색점 좌표 입력:** 각 점의 초기 위치 (t = 0)를 표에서 직접 입력하거나, 좌표를 입력해 새 점 추가
- **벡터 시각화:** 전체 속도 v, 상대속도 v_P/R = ω × r, 전체 가속도 a, 접선·법선 가속도 a_t, a_n
- **각운동 표기:** 기준점 R 둘레에 ω, α를 곡선 화살표로 표시 (↺ 반시계 +, ↻ 시계 −)
- **영속도 순간중심 (ICZV):** 매 순간 속도가 0인 점 C의 위치를 표시
- **점 이동 궤적:** 지나온 경로(실선)와 전체 경로(점선)를 표시
- **실시간 수식 대입:** 선택한 점에 대해 v_P = v_R + ω × r, a_P = a_R + α × r − ω² r 에 현재 값을 대입한 식
- **프리셋:** 일반 평면운동, 순수 병진, 고정축 회전, 구름 바퀴(미끄럼 없음)

## 사용 방법

- 재생 버튼 또는 시간 슬라이더로 0 ~ 10 s 사이의 운동을 확인합니다.
- 캔버스를 **클릭**하면 해당 위치에 강체와 함께 움직이는 탐색점이 추가됩니다.
- **드래그**로 이동하고 **마우스 휠**로 확대·축소할 수 있습니다. "기준점 따라가기"를 켜면 시점이 기준점 R을 따라갑니다.
- 각 창의 **−/+** 버튼으로 최소화하고, 모서리를 끌어 높이를 조절할 수 있습니다.
- 가운데와 오른쪽 끝의 **⋮** 손잡이로 열 폭을 조절할 수 있습니다.
- 캔버스 오른쪽 위 **⤢** 버튼으로 캔버스를 화면 가득 볼 수 있습니다 (Esc 또는 같은 버튼으로 닫기).

### 태블릿 · 스마트폰

- **탭**: 점 추가 · **한 손가락으로 끌기**: 화면 이동 · **두 손가락 벌리기/오므리기**: 확대·축소
- 작은 화면에서는 캔버스 → 운동 매개변수 → 상태 카드 → 형상 → 표 → 수식 순서로 한 열에 배치됩니다.
- 가로 화면이나 작은 폰에서는 **⤢ 전체화면** 버튼을 쓰면 캔버스를 크게 볼 수 있습니다.
- 표는 좌우로 밀어서 나머지 열(가속도, 삭제 버튼)을 볼 수 있습니다.

## 계산 방식

기준점 R의 등가속도 병진운동과 강체의 등각가속도 회전운동을 해석적으로 계산합니다.

- r_R(t) = r_R0 + v_R0 t + ½ a_R t², θ(t) = ω₀ t + ½ α t², ω(t) = ω₀ + α t
- v_P = v_R + ω × r_P/R, a_P = a_R + α × r_P/R − ω² r_P/R
- r_C/R = (ω × v_R) / ω²

부호 규약: x는 오른쪽 +, y는 위쪽 +, 각속도·각가속도는 반시계방향 +.

인터넷 연결이 필요합니다 (KaTeX, Font Awesome, 웹 폰트를 CDN에서 불러옵니다).
