### CH06 강체 평면운동역학

세 탭은 같은 강체·같은 힘으로 계산한 **하나의 운동**을 서로 다른 관점(운동 방정식 · 일과 에너지 · 충격량과 운동량)으로 보여 줍니다. 단위는 SI (m, kg, N, s).

1. **힘·질량·가속도 (F = mā, 교재 6/2–6/5절):** ΣF = mā, ΣM_G = Īα, 임의의 점 P에 대해 ΣM_P = Īα + ρ̄ × mā = I_Pα + ρ̄ × m a_P (I_P = Ī + mρ̄²)
   - **자유물체도 = 운동 선도 그림:** 왼쪽에 떼어 낸 강체에 작용하는 모든 힘(외력·무게·반력), 오른쪽에 m ā와 Ī α를 같은 축척으로 나란히 그리고, 기준점 P에서 각 힘의 작용선까지 모멘트 팔 d를 표시. 축척은 전체 운동(0 ~ T)에 맞춰 한 번 정하므로 재생하는 동안 화살표 길이와 확대 배율이 바뀌지 않음 (핀이 있으면 O, 없으면 G를 그림의 같은 자리에 둠)
   - **모멘트 기준점 P:** G, 핀 O, 접촉점 C, 모서리 A·B, 힘의 작용점, 관찰점, 가속도 0인 점 Z, 순간중심 IC 중에서 고르거나, 그림을 클릭·드래그하거나, **좌표 (x, y)를 직접 입력**해 임의의 점으로 지정. 좌표는 물체 좌표(G 원점, P가 강체와 함께 움직임) 또는 고정 좌표(P가 평면 위에 머묾)로 입력. 예제를 불러오면 교재 풀이와 같은 점이 먼저 선택됨 (진자 O, 구름 C, 상자 A)
   - **"P 기준" 운동 선도:** m ā = m a_P + m α × ρ̄ − m ω² ρ̄로 나누어, Īα + mρ̄²α = I_Pα (평행축 정리)가 되는 과정을 표시
   - **P에 대한 운동 방정식 패널:** ΣF, ΣM_P(P를 지나는 반력은 0으로 빠짐), Īα + ρ̄ × mā, I_P와 a_P를 대입해 세 값이 같음을 확인. ΣM_P = I_Pα를 쓸 수 있는지 판정 (P = G, a_P = 0, a_P ∥ ρ̄일 때만 가능, 순간중심에서는 일반적으로 불가), 하중별 모멘트 표와 여러 기준점의 비교표
   - 자유물체도(외력 + 반력) 표, 각 점의 위치·속도·가속도 표, 운동 방정식 대입 풀이
   - 예제: 막대 끝에 힘(가속도 0인 점 = 타격 중심), 우력만 작용, 막대 진자(고정축 회전, 핀 반력), **교재 예제 6/4**(진자의 베어링 힘, θ = 60° 순간에서 O = 155.6 N), 원판 구름·미끄럼 판정, 바닥 위 상자 밀기(병진·전도)
2. **일과 에너지 (교재 6/6–6/7절):** T = ½mv̄² + ½Īω², 각 힘이 한 일 U = ∫F·v_P dt, T₁ + U₁₋₂ = T₂, T₁ + V₁ + U′ = T₂ + V₂, 일률 P = dT/dt
   - 에너지의 시간 그래프(T, ΔV, U′, 보존 확인선), 하중별 일·일률 표 (핀 반력·수직항력·구름 마찰은 일 0)
   - 예제: 막대 진자(에너지 보존), **교재 예제 6/4**를 에너지로 풀기(ω² = 48.8), 스프링 진자(탄성 에너지), 구름과 미끄럼에서 마찰력의 일, 일정한 힘의 일 F·Δr
3. **충격량과 운동량 (교재 6/8절):** G = mv̄, H_G = Īω, H_O = Īω + r̄ × mv̄, G₁ + ∫ΣF dt = G₂, (H)₁ + ∫ΣM dt = (H)₂
   - 운동량의 시간 그래프, 하중별 선충격량·각충격량 표 (반력 포함)
   - 예제: 막대 끝 타격(짧은 충격), 매달린 막대 타격(타격 중심에서 핀 반력 충격량 0), 우력 충격, 구름 바퀴

#### 힘 주기 (캔버스)

- **강체를 누른 채 끌기:** 누른 점에 새 힘이 생기고, 끈 방향·길이가 힘의 방향·크기가 됩니다 (탭만 하면 기본 크기의 힘)
- **화살표 끝 ○ 끌기:** 힘의 크기·방향 조절 · **작용점 ● 끌기:** 강체 위에서 작용점 이동 · **스프링 고정점 ■ 끌기:** 고정점 이동 · **우력의 ◆ 끌기:** 우력을 그리는 위치 이동
- **빈 곳 끌기:** 화면 이동 · 휠/두 손가락: 확대·축소 · **[관찰점]** 도구: 강체를 클릭하면 관찰점(속도·가속도·궤적 표시) 추가
- 왼쪽 **작용 힘과 우력** 카드에서 각 힘의 작용점·성분(또는 크기·방향각)·작용 시간(시작~끝)과 방향 방식(공간에 고정 / 물체와 함께 회전)을 숫자로 입력할 수 있고, 스프링(고정점·강성 k·자유 길이), 우력 M, 중력 W = mg도 추가할 수 있습니다.
- **우력에는 작용점이 없습니다:** 우력은 크기가 같고 방향이 반대인 두 힘(M = Fd)이라 합력이 0이고 어느 점에 대한 모멘트도 M으로 같은 자유 벡터입니다. 카드의 "그리는 위치"는 그림에 그릴 곳일 뿐이며, 옮겨도 운동·반력·모든 식의 값이 변하지 않습니다.
- **시각화 요소:** 처음에는 각 탭의 주제에 필요한 것만 켜져 있습니다 (① 힘·ā·α, ② 힘·v̄·ω·궤적, ③ 힘·v̄·ω). 켜고 끈 상태는 탭마다 따로 기억되고, 예제를 불러오면 처음 상태로 돌아갑니다.

#### 강체와 구속 조건

- **형상 (균일한 얇은 판):** 직사각형 판, 원판, 얇은 링, 가는 막대, L-형 판 — 질량 m과 치수에서 Ī (회전 반경 k̄)를 계산
- **구속 조건:** 자유 운동(일반 평면운동) · 병진(회전만 구속) · 매끄러운 바닥 위 직선 병진(직사각형은 앞뒤 바닥 반력 N_A, N_B와 전도 경고) · 고정축 회전(핀 O, 강체 위 임의의 점) · 구름(원판·링, μ_s·μ_k로 미끄럼 판정)
- **처음 상태:** θ₀, v̄₀, ω₀와 계산 시간 T

#### 계산 방식

매 순간 구속 조건에 맞는 운동 방정식으로 ā, α와 반력을 구하고 4차 룽게-쿠타법(Δt ≤ 2 ms, 힘이 켜지고 꺼지는 순간에 맞춰 나눔)으로 0 ~ T초를 미리 적분합니다. 각 하중의 일·충격량·각충격량도 함께 적분하므로 T₀ + ΣU = T, G₀ + Σ∫F dt = G가 수치 오차 범위에서 맞는 것을 표에서 확인할 수 있습니다. 구름에서는 매 단계 먼저 미끄럼 없음을 가정하고 |F| ≤ μ_s N을 확인하며, 미끄럼 속도가 0이 되는 순간을 찾아 다시 구름을 검사합니다. 힘을 바꾸면 t = 0부터 다시 계산합니다 (t > 0에서 끄는 동안에는 자세를 고정하고, 손을 떼면 다시 계산).

## 주요 기능 (CH05 ① 강체 평면운동)

- **강체 형상:** 곡선형 임의 강체, L-형 바, 원형 바퀴, 직사각형 판, 사용자 지정 다각형
- **형상 치수 입력 (m):** 바퀴 반지름 r, L-바의 막대 길이 L₁·L₂와 두께 w, 직사각형 b × h, 다각형 꼭짓점 좌표
- **운동 기준점 R:** 강체 위의 임의의 점을 기준점으로 선택하고, 그 점에 병진 속도·가속도를 직접 부여
- **운동 매개변수:** 기준점 병진 속도 v_R, 병진 가속도 a_R, 초기 각속도 ω₀, 각가속도 α (슬라이더 + 숫자 직접 입력)
- **탐색점 좌표 입력:** 각 점의 초기 위치 (t = 0)를 표에서 직접 입력하거나, 좌표를 입력해 새 점 추가
- **벡터 시각화:** 전체 속도 v, 상대속도 v_P/R = ω × r, 전체 가속도 a, 접선·법선 가속도 a_t, a_n
- **각운동 표기:** 기준점 R 둘레에 ω, α를 곡선 화살표로 표시 (↺ 반시계 +, ↻ 시계 −)
- **영속도 순간중심 (ICZV):** 매 순간 속도가 0인 점 C의 위치를 표시
- **점 이동 궤적:** 지나온 경로(실선)와 전체 경로(점선)를 표시
- **실시간 수식 대입:** 선택한 점에 대해 v_P = v_R + ω × r, a_P = a_R + α × r − ω² r 에 현재 값을 대입한 식
- **프리셋:** 일반 평면운동, 순수 병진, 고정축 회전, 구름 바퀴(미끄럼 없음)

## 사용 방법

- 재생 버튼 또는 시간 슬라이더로 0 ~ 10 s 사이의 운동을 확인합니다.
- 캔버스를 **클릭**하면 해당 위치에 강체와 함께 움직이는 탐색점이 추가됩니다.
- **드래그**로 이동하고 **마우스 휠**로 확대·축소할 수 있습니다. "기준점 따라가기"를 켜면 시점이 기준점 R을 따라갑니다.
- 각 창의 **−/+** 버튼으로 최소화하고, 모서리를 끌어 높이를 조절할 수 있습니다.
- 가운데와 오른쪽 끝의 **⋮** 손잡이로 열 폭을 조절할 수 있습니다.
- 캔버스 오른쪽 위 **⤢** 버튼으로 캔버스를 화면 가득 볼 수 있습니다 (Esc 또는 같은 버튼으로 닫기).

### 태블릿 · 스마트폰

- **탭**: 점 추가 · **한 손가락으로 끌기**: 화면 이동 · **두 손가락 벌리기/오므리기**: 확대·축소
- 작은 화면에서는 캔버스 → 운동 매개변수 → 상태 카드 → 형상 → 표 → 수식 순서로 한 열에 배치됩니다.
- 가로 화면이나 작은 폰에서는 **⤢ 전체화면** 버튼을 쓰면 캔버스를 크게 볼 수 있습니다.
- 표는 좌우로 밀어서 나머지 열(가속도, 삭제 버튼)을 볼 수 있습니다.

## 계산 방식 (CH05 ① 강체 평면운동)

기준점 R의 등가속도 병진운동과 강체의 등각가속도 회전운동을 해석적으로 계산합니다.

- r_R(t) = r_R0 + v_R0 t + ½ a_R t², θ(t) = ω₀ t + ½ α t², ω(t) = ω₀ + α t
- v_P = v_R + ω × r_P/R, a_P = a_R + α × r_P/R − ω² r_P/R
- r_C/R = (ω × v_R) / ω²

부호 규약: x는 오른쪽 +, y는 위쪽 +, 각속도·각가속도는 반시계방향 +.

인터넷 연결이 필요합니다 (KaTeX, Font Awesome, 웹 폰트를 CDN에서 불러옵니다).
