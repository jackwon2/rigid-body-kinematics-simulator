선택점의 상대운동 수식 대입 (Real-time Equations)

현재 시각의 기준점 $R$ 운동과 강체 각운동 $(\omega, \alpha)$를 상대운동 식에 직접 대입한 결과입니다. 2차원에서 $\boldsymbol{\omega}\times\mathbf{r} = \omega(-r_y,\ r_x)$ 입니다.

강체 평면 운동학 핵심 원리 (Key Principles)

① 모든 점에서 동일한 $\omega$, $\alpha$

강체 내 임의의 두 선분 사이 각도 $\beta$는 변하지 않으므로, 어떤 선분을 택해도 회전각의 변화율(각속도·각가속도)은 같습니다. 즉 $\omega$, $\alpha$는 강체 전체의 성질입니다.

$$\theta_2 = \theta_1 + \beta \;\Rightarrow\; \dot\theta_1 = \dot\theta_2 = \omega,\quad \ddot\theta_1 = \ddot\theta_2 = \alpha$$

② 상대속도: 병진 + 회전의 합성

점 $P$의 속도는 기준점 $R$의 병진 속도와, $R$에 대한 순수 회전에 의한 상대속도의 벡터합입니다. 상대속도는 $\mathbf{r}_{P/R}$에 수직이고 크기는 $\omega r$입니다.

$$\mathbf{v}_P = \mathbf{v}_R + \mathbf{v}_{P/R} = \mathbf{v}_R + \boldsymbol{\omega}\times\mathbf{r}_{P/R}$$

③ 상대가속도: 접선 + 법선 성분

$R$에 대한 상대가속도는 $\mathbf{r}_{P/R}$에 수직인 접선 성분 $(\alpha r)$과 $R$을 향하는 법선(구심) 성분 $(\omega^2 r)$으로 나뉩니다.

$$\mathbf{a}_P = \mathbf{a}_R + \underbrace{\boldsymbol{\alpha}\times\mathbf{r}_{P/R}}_{(\mathbf{a}_{P/R})_t} \underbrace{-\,\omega^2\,\mathbf{r}_{P/R}}_{(\mathbf{a}_{P/R})_n}$$

④ 영속도 순간중심 (ICZV)

$\omega \neq 0$이면 매 순간 속도가 0인 점 $C$가 존재하며, 그 순간 강체는 $C$를 중심으로 순수 회전합니다. ($C$의 가속도는 일반적으로 0이 아닙니다.)

$$\mathbf{r}_{C/R} = \frac{\boldsymbol{\omega}\times\mathbf{v}_R}{\omega^2}\;\Rightarrow\;\mathbf{v}_C = \mathbf{0},\qquad v_P = \omega\, r_{P/C}$$

⑤ 이 시뮬레이터의 운동 모델 (등가속 병진 + 등각가속 회전)

$$\mathbf{r}_R(t) = \mathbf{r}_{R,0} + \mathbf{v}_{R,0}\,t + \tfrac12\,\mathbf{a}_R\,t^2,\qquad \theta(t) = \omega_0 t + \tfrac12\alpha t^2,\qquad \omega(t) = \omega_0 + \alpha t$$

부호 규약: x는 오른쪽 +, y는 위쪽 +, 각속도·각가속도는 반시계방향 +. 구름 바퀴(미끄럼 없음, 반지름 $r$)는 $v_O = -\omega r$, $a_O = -\alpha r$이고 순간중심이 접촉점과 일치합니다.
