선택점의 상대운동 수식 대입 (Real-time Equations)

현재 시각의 기준점 $R$ 운동과 강체 각운동 $(\omega, \alpha)$를 상대운동 식에 직접 대입한 결과입니다. 2차원에서 $\boldsymbol{\omega}\times\mathbf{r} = \omega(-r_y,\ r_x)$ 입니다.

강체 평면 운동학 핵심 원리 (Key Principles)

① 모든 점에서 동일한 $\omega$, $\alpha$

강체 내 임의의 두 선분 사이 각도 $\beta$는 변하지 않으므로, 어떤 선분을 택해도 회전각의 변화율(각속도·각가속도)은 같습니다. 즉 $\omega$, $\alpha$는 강체 전체의 성질입니다.

$$\theta_2 = \theta_1 + \beta \;\Rightarrow\; \dot\theta_1 = \dot\theta_2 = \omega,\quad \ddot\theta_1 = \ddot\theta_2 = \alpha$$

② 상대속도: 병진 + 회전의 합성

점 $P$의 속도는 기준점 $R$의 병진 속도와, $R$에 대한 순수 회전에 의한 상대속도의 벡터합입니다. 상대속도는 $\mathbf{r}_{P/R}$에 수직이고 크기는 $\omega r$입니다.

$$\mathbf{v}_P = \mathbf{v}_R + \mathbf{v}_{P/R} = \mathbf{v}_R + \boldsymbol{\omega}\times\mathbf{r}_{P/R}$$

③ 상대가속도: 접선 + 법선 성분

$R$에 대한 상대가속도는 $\mathbf{r}_{P/R}$에 수직인 접선 성분 $(\alpha r)$과 $R$을 향하는 법선(구심) 성분 $(\omega^2 r)$으로 나뉩니다.

$$\mathbf{a}_P = \mathbf{a}_R + \underbrace{\boldsymbol{\alpha}\times\mathbf{r}_{P/R}}_{(\mathbf{a}_{P/R})_t} \underbrace{-\,\omega^2\,\mathbf{r}_{P/R}}_{(\mathbf{a}_{P/R})_n}$$

④ 영속도 순간중심 (ICZV)

$\omega \neq 0$이면 매 순간 속도가 0인 점 $C$가 존재하며, 그 순간 강체는 $C$를 중심으로 순수 회전합니다. ($C$의 가속도는 일반적으로 0이 아닙니다.)

$$\mathbf{r}_{C/R} = \frac{\boldsymbol{\omega}\times\mathbf{v}_R}{\omega^2}\;\Rightarrow\;\mathbf{v}_C = \mathbf{0},\qquad v_P = \omega\, r_{P/C}$$

⑤ 이 시뮬레이터의 운동 모델 (등가속 병진 + 등각가속 회전)

$$\mathbf{r}_R(t) = \mathbf{r}_{R,0} + \mathbf{v}_{R,0}\,t + \tfrac12\,\mathbf{a}_R\,t^2,\qquad \theta(t) = \omega_0 t + \tfrac12\alpha t^2,\qquad \omega(t) = \omega_0 + \alpha t$$

부호 규약: x는 오른쪽 +, y는 위쪽 +, 각속도·각가속도는 반시계방향 +. 구름 바퀴(미끄럼 없음, 반지름 $r$)는 $v_O = -\omega r$, $a_O = -\alpha r$이고 순간중심이 접촉점과 일치합니다.

상대속도 · 상대가속도 식 대입 (Vector Solution)

교재의 벡터 풀이와 같은 순서로 현재 자세의 값을 대입했습니다. 2차원에서 $\boldsymbol{\omega}\times\mathbf{r} = \omega(-r_y,\ r_x)$ 이고, 길이·속도·가속도는 결과 표시 단위입니다.

링크 기구 해석의 핵심 원리 (Key Principles)

① 같은 링크 위 두 점의 상대속도

링크 AB 위의 A를 B와 함께 병진하는 관측자가 보면 A는 B를 중심으로 원운동을 합니다. 그래서 상대속도는 항상 AB에 수직이고 크기는 $r\omega$ 입니다.

$$\mathbf v_A = \mathbf v_B + \mathbf v_{A/B},\qquad \mathbf v_{A/B} = \boldsymbol\omega_{AB}\times\mathbf r_{A/B}\ \perp AB$$

② 상대가속도 = 법선 + 접선

법선 성분은 기준점 B를 향하고 $(r\omega^2)$, 접선 성분은 AB에 수직입니다 $(r\alpha)$. 법선 성분이 ω에 의존하므로 속도 해석을 먼저 합니다.

$$\mathbf a_A = \mathbf a_B \underbrace{-\,\omega_{AB}^2\,\mathbf r_{A/B}}_{(\mathbf a_{A/B})_n} + \underbrace{\boldsymbol\alpha_{AB}\times\mathbf r_{A/B}}_{(\mathbf a_{A/B})_t}$$

③ 벡터식 1개 = 스칼라식 2개

2차원 벡터식으로는 미지수를 2개까지 구할 수 있습니다. 크랭크-슬라이더는 $v_A$의 방향(실린더 축)을 알므로 미지수가 $v_A$, $\omega_{AB}$이고, 4절 링크는 $\omega_{AB}$, $\omega_{OA}$ (가속도에서는 $\alpha_{AB}$, $\alpha_{OA}$) 입니다.

$$\boldsymbol\omega_{OA}\times\mathbf r_{A/O} = \boldsymbol\omega_{CB}\times\mathbf r_{B/C} + \boldsymbol\omega_{AB}\times\mathbf r_{A/B}$$

④ 커플러의 영속도 순간중심

각 점의 속도에 그은 수선들의 교점입니다. 4절 링크에서는 두 고정 링크의 연장선 교점, 크랭크-슬라이더에서는 OB 연장선과 A에서 실린더 축에 세운 수선의 교점입니다. 순간중심의 가속도는 0이 아니므로 가속도 해석의 기준점으로 쓰지 않습니다.

$$v_A = \omega_{AB}\,\overline{AI},\qquad v_B = \omega_{AB}\,\overline{BI}$$

⑤ 이 탭의 해석 방식 (자세별 순간 해석)

주어진 구동 각 θ에서 먼저 각 관절의 위치를 구하고(자세 해석), 그 자세에서 주어진 ω, α로 속도·가속도를 계산합니다. 교재의 “그림에 표시된 자세에서” 푸는 방식과 같습니다. 재생은 θ를 ω 방향으로 천천히 돌려 여러 자세를 차례로 보여 주며, 실제 시간 축은 아닙니다. 4절 링크에서 구동 링크가 한 바퀴를 돌 수 없으면 (그라스호프 조건을 만족하지 않으면) 조립 가능한 θ 범위만 재생합니다.

$$\text{그라스호프 조건: } s + l \le p + q \;\Rightarrow\; \text{가장 짧은 링크가 한 바퀴 회전 가능}$$

회전 좌표계에 대한 상대운동 (Key Principles, Art. 5/7)

① 상대속도 (식 5/12)

원점 B에 붙어 각속도 ω로 도는 좌표계 x-y에서 A의 위치를 $\mathbf r = x\mathbf i + y\mathbf j$로 쓰면, 회전하는 단위벡터의 미분 $\dot{\mathbf i} = \boldsymbol\omega\times\mathbf i$, $\dot{\mathbf j} = \boldsymbol\omega\times\mathbf j$ 때문에 항이 하나 더 생깁니다.

$$\mathbf v_A = \mathbf v_B + \boldsymbol\omega\times\mathbf r + \mathbf v_{\rm rel},\qquad \mathbf v_{\rm rel} = \dot x\,\mathbf i + \dot y\,\mathbf j$$

② 상대가속도 (식 5/14)

한 번 더 미분하면 다섯 항이 됩니다. 마지막 두 항은 회전 좌표계의 관측자가 잰 A의 운동과 관계된 항입니다.

$$\mathbf a_A = \mathbf a_B + \dot{\boldsymbol\omega}\times\mathbf r + \boldsymbol\omega\times(\boldsymbol\omega\times\mathbf r) + 2\boldsymbol\omega\times\mathbf v_{\rm rel} + \mathbf a_{\rm rel}$$

③ 일치점 P로 보기

그 순간 A와 겹치는, 회전하는 판에 고정된 점 P를 생각하면 앞의 항들은 P의 운동, 뒤의 항들은 P에 대한 A의 운동입니다.

$$\mathbf v_A = \underbrace{\mathbf v_B + \boldsymbol\omega\times\mathbf r}_{\mathbf v_P} + \mathbf v_{\rm rel},\qquad \mathbf a_A = \underbrace{\mathbf a_B + \dot{\boldsymbol\omega}\times\mathbf r + \boldsymbol\omega\times(\boldsymbol\omega\times\mathbf r)}_{\mathbf a_P} + 2\boldsymbol\omega\times\mathbf v_{\rm rel} + \mathbf a_{\rm rel}$$

④ 코리올리 가속도 $2\boldsymbol\omega\times\mathbf v_{\rm rel}$

$\mathbf v_{\rm rel}$에 수직이고, $\mathbf v_{\rm rel}$을 ω의 회전 방향으로 90° 돌린 방향입니다. 회전하는 슬롯에서 $\mathbf v_{\rm rel}$의 방향이 바뀌는 효과($\dot x\,\omega$)와 반지름이 변하면서 $x\omega$가 커지는 효과($\omega\dot x$)가 더해져 $2\omega\dot x$가 됩니다.

$$\mathbf a_{A/P} = 2\boldsymbol\omega\times\mathbf v_{\rm rel} + \mathbf a_{\rm rel} \;\neq\; \mathbf a_{\rm rel}$$

⑤ 곡선 경로에서의 $\mathbf a_{\rm rel}$

회전 좌표계에서 본 경로가 곡선이면 $\mathbf a_{\rm rel}$에는 경로 방향 성분과, 곡률 중심을 향하는 성분이 있습니다 (ρ = 회전 좌표계에서 잰 곡률 반지름).

$$(a_{\rm rel})_t = \ddot r,\qquad (a_{\rm rel})_n = \frac{v_{\rm rel}^2}{\rho}$$

⑥ 회전하지 않는 좌표계와 비교

병진만 하는 좌표계에서 본 상대운동은 $\mathbf v_{A/B} = \mathbf v_A - \mathbf v_B$, $\mathbf a_{A/B} = \mathbf a_A - \mathbf a_B$ 입니다. 관측자가 회전하면 보이는 운동이 달라집니다 (예제 5/19).

$$\mathbf v_{A/B} = \boldsymbol\omega\times\mathbf r + \mathbf v_{\rm rel} \neq \mathbf v_{\rm rel}$$
